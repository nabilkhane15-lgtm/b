# 🏸 ব্যাডমিন্টন ও স্পোর্টস ক্লাব ফান্ড ম্যানেজার (Badminton & Sports Club Fund Manager)

একটি আধুনিক, রিয়েল-টাইম ক্লাউড-সিঙ্কযুক্ত (Firebase Firestore) স্পোর্টস ক্লাব ও ফান্ড ম্যানেজমেন্ট ওয়েব অ্যাপ্লিকেশন। বাংলা এবং ইংরেজি—উভয় ভাষায় সম্পূর্ণ সাপোর্টসহ তৈরি।

---

## ✨ প্রধান ফিচারসমূহ (Key Features)

### ১. 🔄 মাল্টি-ব্রাউজার ও মাল্টি-ডিভাইস লাইভ ক্লাউড সিঙ্ক (Real-Time Cloud Sync)
- **স্বয়ংক্রিয় সিঙ্ক:** যেকোনো ব্রাউজার বা মোবাইল থেকে নতুন সদস্য সাইন-আপ (Sign-Up) করলে, পেমেন্ট সেভ করলে বা অ্যাডমিন পাসওয়ার্ড পরিবর্তন করলে তা সাথে সাথে **Firebase Firestore** ক্লাউডে সংরক্ষিত হয়।
- **অন্য ব্রাউজারে তাৎক্ষণিক আপডেট:** এক ব্রাউজার বা ডিভাইসে ডাটা যুক্ত বা পরিবর্তন করলে অন্য সব ব্রাউজারে (অ্যাডমিন ও সাধারণ ইউজার উভয়ের কাছে) স্বয়ংক্রিয়ভাবে সাথে সাথে আপডেট দেখা যায়।
- **স্মার্ট ডাটা মার্জ ও স্যানিটাইজেশন:** একাধিক ব্রাউজার থেকে একসাথে সদস্য রেজিস্ট্রেশন বা পেমেন্ট আপডেট করলেও কোনো ডাটা হারায় না।

### ২. 🔐 রোল-ভিত্তিক প্রাইভেসি ও সেটিংস কন্ট্রোল (Role-Based Privacy & Access Control)
- **সাধারণ ভিজিটর (লগইন ছাড়া):** শুধুমাত্র ক্লাবের ড্যাশবোর্ড, সদস্য তালিকা, চাঁদার হিসাব ও রিপোর্ট দেখতে পারবেন। সেটিংস (Settings) ট্যাবে ক্লিক করলে কোনো অ্যাডমিন কন্ট্রোল দেখানো হবে না—শুধুমাত্র **সদস্য লগইন / নতুন সাইন-আপ** করার গেটওয়ে দেখাবে।
- **নিবন্ধিত সদস্য (Logged-in Member):** নিজের ৪-সংখ্যার মেম্বার আইডি (যেমন `#1001`) বা মোবাইল নম্বর ও গোপন PIN দিয়ে লগইন করলে সেটিংস ট্যাবে শুধুমাত্র নিজের প্রোফাইল ও পাসওয়ার্ড পরিবর্তনের অপশন দেখতে পারবেন।
- **প্রধান অ্যাডমিন ও সাব-অ্যাডমিন (Master Admin & Sub-Admin):** প্রধান অ্যাডমিন পাসওয়ার্ড দিয়ে লগইন করলে সম্পূর্ণ ক্লাব কন্ট্রোল, ফান্ড ম্যানেজমেন্ট, পাসওয়ার্ড পরিবর্তন ও ক্লাউড ডাটাবেস কন্ট্রোল আনলক হবে।

### ৩. 💰 সম্পূর্ণ হিসাবরক্ষণ (Complete Fund & Collection Tracking)
- **সাপ্তাহিক চাঁদা (Weekly Collection):** প্রতি সপ্তাহের টার্গেট, পেইড/আনপেইড স্ট্যাটাস, বিকাশ/নগদ/ক্যাশ পেমেন্ট ও ডিজিটাল মানি রিসিট।
- **মাসিক চাঁদা ও সঞ্চয় তহবিল (Monthly Fee & Sonsoy/Savings Fund):** মাসিক চাঁদা আদায় এবং সদস্যদের সঞ্চয় জমা ও উত্তোলনের পূর্ণাঙ্গ হিসাব।
- **খরচ ও বিশেষ ফান্ড (Expenses & Custom Funds):** শাটলকক, কোর্ট ভাড়া, লাইটিং ও অন্যান্য খরচের ভাউচার এবং বিশেষ ইভেন্ট ফান্ড।
- **টুর্নামেন্ট, পিকনিক ও লিডারবোর্ড:** টুর্নামেন্ট ব্র্যাকেট, পিকনিক রেজিস্ট্রেশন এবং সেরা খেলোয়াড়দের হল অফ ফেম।

## 🚀 কীভাবে চালাবেন (Local Development)

```bash
# ১. ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ২. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev

# ৩. প্রোডাকশন বিল্ড তৈরি করুন
npm run build
```

## 🌐 GitHub ও Netlify ডিপ্লয়মেন্ট গাইড (Deployment Guide)

এই প্রজেক্টটি যদি **GitHub**-এর মাধ্যমে **Netlify** বা **Vercel**-এ কানেক্ট করা থাকে:
1. Google AI Studio থেকে প্রজেক্টটি **Export to GitHub** বা **Push to GitHub** করুন।
2. GitHub রিপোজিটরিতে নতুন কমিট (Commit) পুশ হওয়ার সাথে সাথে **Netlify** স্বয়ংক্রিয়ভাবে নতুন কোড বিল্ড করে ১–২ মিনিটের মধ্যে আপনার লাইভ ওয়েবসাইট আপডেট করে দেবে।
3. বিল্ড কমান্ড: `npm run build` এবং পাবলিশ ডিরেক্টরি: `dist`।
